The nonprofit droid you're looking for - Complete management system for 501(c)(3) organizations.

== Description ==

A comprehensive WordPress plugin for managing organizational memberships with modular features including email campaigns, event management, financial tracking, and more.

= Core Features =

* Complete member profiles with custom fields
* Password-protected member dashboard
* Full data export/import functionality
* Custom user roles with granular permissions

= Optional Modules =

* Email Management - Bulk emails with approval workflow
* Event Management - Events with RSVP tracking
* Financial Management - Income/expense tracking
* Volunteer Management - Coordinate volunteer opportunities
* Officer Tools - Agendas, minutes, and documents
* Committee Management - Committee structure tracking

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Configure settings under Membership > Settings
4. Set up your dashboard password and organization details

== Frequently Asked Questions ==

= How do I access the member dashboard? =

The member dashboard is available at `/dashboard` on your site. It's password protected for security.

= Can I disable features I don't need? =

Yes! All optional features can be enabled/disabled from the Settings page.

= Is the plugin multisite compatible? =

Currently, the plugin is designed for single-site installations.

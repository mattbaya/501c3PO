Simple CSV import and export for SWCA member data.

== Description ==

A straightforward plugin for importing and exporting SWCA member data via CSV files.

Features:
* Import member data from CSV files
* Export all members to CSV
* View member directory with shortcode [swca_member_directory]
* Simple admin interface
* Automatic table creation

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/swca-simple-export-import/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Use the 'SWCA Data' menu in admin to import/export

== Usage ==

1. Go to SWCA Data in WordPress admin
2. Import: Upload a CSV file with member data
3. Export: Download all member data as CSV
4. Display: Use [swca_member_directory] shortcode on any page
